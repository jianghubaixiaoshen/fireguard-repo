# 报名表填报 · 项目三「哨兵不问网」

## 团队名称

哨兵不问网

## 作品名称及创意简介（289 字）

「哨兵不问网」是一台 4G 火焰报警装置：KY-026 见火即报，AHT20 顺手盯着温湿度，
数据全程走 4G 上云，手机立刻弹窗——WiFi 有没有、宽带断没断，它无所谓。做它的
起点是宿舍那块挤着六七个充电器的插排，和老家没拉网线的仓库：报警这种事，本来
就不该看网的脸色。
它也是份新手踩坑实录：丝印 5 和 6 看着像 GPIO 其实被模组占用；KY-026 存在不同
有效电平的批次，这块实测见火输出高；认证报 -5894 查了几小时网络，真凶是把密钥
里的 l 抄成了 1；最邪门的是「幽灵会话」——APP 显示在线，数据其实早被平台丢弃。
标准从此改成：板子读数和云端日志对得上，才算真在线。
